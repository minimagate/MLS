# MLS — Math Language Server

The repository currently implements M1: a deterministic, offline parser CLI for
TeXmacs native (`.tm`) documents. It finds sections, definitions, theorem-family
environments, equations, and proofs; reports exact-source hashes, labels, and
explicit label dependencies as JSON; and assigns unique UUIDs for the run.
Untagged rendered content in the document body is grouped into commentary blocks,
including its inline formatting and references. Preamble and control arguments
are never treated as prose; a native document without a `body` yields a
`missing_body` diagnostic and no blocks.

Build and run it with Rust 1.99 or newer:

```sh
cargo run -p mls-cli --bin mls -- notes.tm
```

Parsing is read-only by default. Persist generated IDs only when desired:

```sh
cargo run -p mls-cli --bin mls -- --write-ids notes.tm
```

IDs generated by a read-only run are transient. ID writes wrap recognized source
blocks with TeXmacs `with` metadata, preserve all original bytes, and replace the
file atomically after a successful parse.
Malformed tags are errors; duplicate IDs/labels and unresolved references are
reported in the JSON diagnostics array. `--write-ids` refuses invalid or duplicate
ID metadata and symbolic-link targets rather than replacing ambiguous files.
Legacy non-UTF-8 document bytes remain
lossless, although labels and references must be UTF-8 to participate in linking.

Run formatting, lint, unit, property, and CLI integration checks with:

```sh
make test
```

Later milestones are intentionally not implemented yet.
